## Projetos e Publicações Principais

### 1. Plataforma Hub LAFIC/UFSC
**Descrição**: Hub digital integrado para biodiversidade marinha, protocolos de campo, sensoriamento remoto, ciência aberta e gestão costeira.  
**Tecnologias**: HTML, estruturação de conteúdo acadêmico, publicação web  
**Link**: https://caetanoronan.github.io/projeto-hub/

### 2. Mapa de Infraestrutura Logística - Santa Catarina
**Descrição**: Análise interativa de mais de 10.250 elementos de infraestrutura logística com 14 camadas temáticas e 5 gráficos interativos para apoio à leitura territorial.  
**Tecnologias**: Leaflet, Plotly, Python, dados IBGE BC25  
**Link**: https://github.com/caetanoronan/Infra_SC

### 3. Origem das Aves em Theropoda
**Descrição**: Apresentação interativa baseada em Reveal.js sobre a origem evolutiva das aves modernas a partir de dinossauros Theropoda. Inclui scripts Python sofisticados para extração e processamento de imagens científicas de PDFs de pesquisa.  
**Tecnologias**: Reveal.js, Python, HTML5, CSS3, processamento de PDFs e imagens  
**Link**: https://github.com/caetanoronan/origem-aves-theropoda

### 4. Geomarketing Drones Agrícolas - Santa Catarina
**Descrição**: Análise de mercado geoespacial para identificar potencial de drones agrícolas em 295 municípios, usando dados IBGE PAM 2024.  
**Tecnologias**: Python, Folium, IBGE SIDRA, análise territorial  
**Link**: https://github.com/caetanoronan/geomarketing-drones-sc

### 5. Análise de Resíduos Sólidos - Santa Catarina
**Descrição**: Leitura geoespacial da geração de resíduos sólidos em 16.831 setores censitários, com design acessível para daltonismo.  
**Tecnologias**: Python, GeoPandas, Folium, dados IBGE Censo 2022  
**Link**: https://github.com/caetanoronan/portfolio-residuos-sc

### 6. Monitoramento Costeiro - Praia dos Ingleses
**Descrição**: Projeto de pesquisa ambiental para monitorar mudanças na orla costeira utilizando dados de aerofotogrametria e análise geoespacial.  
**Tecnologias**: Leaflet, Python, GeoPackage, GitHub Pages  
**Link**: https://github.com/caetanoronan/monitoramento-costeiro-ingleses
