# Estrutura do Portfólio

## 📂 Diretórios

```
caetanoronan/
├── README.md                 # Página principal do portfólio
├── .gitignore               # Arquivos a ignorar no git
├── projects/                # Documentação dos projetos
│   ├── README.md
│   ├── projeto-1.md
│   └── projeto-2.md
├── assets/                  # Imagens, screenshots, etc
│   ├── profile.jpg
│   └── project-screenshots/
├── CURRICULO.md             # Currículo em formato markdown
└── ROADMAP.md               # Metas e objetivos futuros
```

## 🎨 Dicas de Organização

1. **README.md**: Sua "homepage" no GitHub
2. **projects/**: Cada projeto em um arquivo separado com documentação
3. **assets/**: Armazene imagens e screenshots dos projetos
4. **CURRICULO.md**: Versão digital do seu CV
5. **.gitignore**: Configure para não versionar arquivos desnecessários
