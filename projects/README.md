# 📁 Projetos do Portfólio

## 📝 Como adicionar novos projetos

1. Crie um novo arquivo `.md` em `projects/` com o nome do projeto.
2. Inclua descrição, objetivo, tecnologias, resultados e links.
3. Adicione o link no `README.md` principal e, se fizer sentido, nesta página.
