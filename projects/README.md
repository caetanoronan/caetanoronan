# Projetos do Portfólio

Este diretório contém documentação e links para meus principais projetos.

## Como adicionar seus projetos:

1. Crie um arquivo `.md` para cada projeto
2. Use o seguinte template:

```markdown

## 📝 Descrição
[Descrição detalhada do projeto]

## 🎯 Objetivo
[Por que foi criado]

## 💻 Tecnologias Utilizadas
- Linguagem 1
- Framework 1
- Ferramenta 1

## 🚀 Funcionalidades
- [ ] Funcionalidade 1
- [ ] Funcionalidade 2
- [ ] Funcionalidade 3

## 📊 Resultados/Aprendizados
[O que aprendeu com o projeto]

## 🔗 Links
- [Repositório](link)
- [Demo Live](link)
- [Documentação](link)
```
