# 🗺️ Mapa de Infraestrutura Logística - Santa Catarina

## 📝 Descrição
Projeto completo e interativo de visualização e análise de infraestrutura logística de Santa Catarina. Integra 10.250+ elementos geográficos em 14 camadas de dados, utilizando dados oficiais do IBGE (BC25 - 2020).

## 🎯 Objetivo
Criar uma plataforma visual e analítica que permita explorar e analisar a complexa rede de infraestrutura de transportes em Santa Catarina, gerando insights estratégicos para planejamento logístico.

## 💻 Tecnologias Utilizadas
- **Geoespacial**: Leaflet.js, QGIS
- **Frontend**: HTML5, CSS3, JavaScript
- **Análise de Dados**: Plotly.js
- **Dados**: IBGE (BC25 2020), shapefiles
- **Backend**: Python (análise de dados)
- **Deploy**: GitHub Pages

## 📊 Dados & Escala

### 10.250+ Elementos em 14 Camadas:
- 🛣️ **7.900 Rodovias** (10.840+ km)
- 🚂 **74 Ferrovias** (500+ km)
- ⛵ **223 Infraestruturas Marítimas** (terminais, portos)
- 🌉 **1.622 Obras de Arte** (pontes, viadutos, túneis)
- ✈️ **117 Infraestruturas Aéreas** (helipontos)
- 🌊 **Hidrovias e Dutos** (200+ km)
- 🗺️ **295 Municípios** (classificados por porte)

## 🎨 Features Principais
