# 🌊 Portfolio - Análise de Resíduos Sólidos - Santa Catarina

## 📝 Descrição
Portfolio acadêmico de análise geoespacial para estimativa de geração de resíduos sólidos domésticos em Santa Catarina. Combina dados do Censo Demográfico 2022 (IBGE) com divisões territoriais por bacias hidrográficas, criando visualizações interativas com design acessível para pessoas com daltonismo.

## 🎯 Objetivo
Estimar e visualizar a geração de resíduos sólidos nos 295 municípios de Santa Catarina, agregando dados por setor censitário, município, região e bacia hidrográfica. Fornecer análises que subsidiem políticas públicas de gestão ambiental integrada.

## 💻 Tecnologias Utilizadas
- **Análise de Dados**: Python 3.13, Pandas, GeoPandas
- **Visualização**: Folium, Matplotlib, Plotly
- **Dados Geográficos**: Shapefiles, GeoJSON (16.831 setores censitários)
- **Design**: Mobile-first, acessibilidade WCAG 2.1
- **Deploy**: GitHub Pages
- **API**: IBGE (dados censitários e populacionais)

## 🎨 Features Principais
- ✅ Análise de 16.831 setores censitários
- ✅ Estimativas de geração de resíduos por setor (0.95 kg/hab/dia)
- ✅ Agregação por município, região e bacia hidrográfica
- ✅ Mapas interativos com Folium
- ✅ Design mobile-first responsivo
- ✅ Acessibilidade para daltonismo (paleta de cores específica)
- ✅ Conformidade WCAG 2.1
- ✅ Dashboard com múltiplas visualizações
- ✅ Análise de resíduos recicláveis (10% do total)

## 📊 Dados & Escala

### Estrutura Geográfica:
- **16.831 setores censitários** (IBGE Censo 2022)
- **295 municípios** de Santa Catarina
- **8 bacias hidrográficas** macro-regionais
- **População**: Projeções municipais via API IBGE

### Estimativas:
- Geração doméstica: 0.95 kg/habitante/dia
- Resíduos recicláveis: ~10% do total
- Projeção anual por município
