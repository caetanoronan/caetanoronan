# 🏖️ Monitoramento Costeiro - Praia dos Ingleses

## 📝 Descrição
Projeto de pesquisa do IFSC (Campus Florianópolis) para monitorar o alargamento artificial da orla e a dinâmica das dunas urbanas na Praia dos Ingleses. Utiliza aerofotogrametria, análise espacial e visualização de dados geográficos.

## 🎯 Objetivo
Analisar e monitorar mudanças geomorfológicas em zona costeira urbana, integrando dados de sensoriamento remoto, processamento geoespacial e análise ambiental.

## 💻 Tecnologias Utilizadas
- **Geoespacial**: QGIS, Leaflet.js, Turf.js
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python (GeoPandas, Geopandas)
- **Dados**: GeoPackage (IBGE), shapefiles
- **Deploy**: GitHub Pages (hospedagem estática)

## 🎨 Features Principais
- ✅ Apresentação HTML com tema escuro e abas
- ✅ Mapa interativo Leaflet com múltiplas camadas
- ✅ Análise de setores usando GeoPackage (SC_setores_CD2022)
- ✅ Buffer de 100m para análise de zona de influência
- ✅ Visualização de área alargada e dunas urbanas
- ✅ Dados públicos e acessíveis online

## 📊 Resultados & Aprendizados
- Experiência com ferramentas de geoprocessamento profissionais
- Desenvolvimento de aplicações web para dados geoespaciais
- Análise de mudanças costeiras e impacto ambiental
- Publicação de dados geográficos de forma acessível
- Integração de dados públicos (IBGE) em projetos
