# 📚 Apostila Arrais

## 📝 Descrição
Apostila digital desenvolvida em HTML para formação de arrais (mestres de embarcações). Projeto demonstra capacidade de criar materiais educacionais estruturados e publicáveis via web, com integração de recursos multimídia.

## 🎯 Objetivo
Disponibilizar material educacional de qualidade para formação de arrais em formato digital acessível, publicável via GitHub Pages com suporte a imagens e recursos integrados.

## 💻 Tecnologias Utilizadas
- **Frontend**: HTML5, CSS3, JavaScript
- **Hospedagem**: GitHub Pages
- **Versionamento**: Git, GitHub
- **Recursos**: Imagens integradas, estrutura responsiva
- **Configuração**: .nojekyll para otimização GitHub Pages

## 🎨 Features Principais
- ✅ Apostila completa em HTML
- ✅ Integração de imagens e recursos
- ✅ Design responsivo para múltiplos dispositivos
- ✅ Otimizado para publicação em GitHub Pages
- ✅ Estrutura clara e navegável
- ✅ Suporte a processamento sem Jekyll

## 📋 Conteúdo
- Apostila_arras_teste_08_clone.html - Documento principal
- Imagens e recursos integrados
- Branch gh-pages para publicação
- Arquivo .nojekyll para otimização

## 📊 Resultados & Aprendizados
- Experiência em criação de materiais educacionais digitais
- Publicação de conteúdo HTML em GitHub Pages
- Integração de recursos multimídia em documentos
- Otimização para diferentes plataformas
- Capacidade de estruturar conhecimento técnico em formato pedagógico
