# Aplicação Web Interativa

## 📝 Descrição
Uma aplicação web moderna desenvolvida com React e Node.js que demonstra boas práticas de desenvolvimento full-stack. A aplicação oferece uma interface intuitiva e responsiva.

## 🎯 Objetivo
Criar um projeto demonstrando domínio em frontend moderno com React, backend com Node.js/Express e integração com banco de dados.

## 💻 Tecnologias Utilizadas
- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, JWT
- **Banco de Dados**: PostgreSQL
- **Ferramentas**: Docker, Git, Postman
- **Deploy**: Vercel, Heroku

## 🎨 Features Principais
- ✅ Autenticação com JWT
- ✅ CRUD completo (Create, Read, Update, Delete)
- ✅ Validação de formulários
- ✅ Interface responsiva
- ✅ Tratamento de erros robusto
- ✅ Testes unitários

## 📊 Resultados & Aprendizados
- Melhorou minha compreensão de arquitetura REST API
- Aprendi sobre boas práticas de segurança web (CORS, JWT, validação)
- Experiência com CI/CD pipelines
- Melhorou performance com otimizações React (memo, useMemo)
