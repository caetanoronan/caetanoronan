# 🦅 Origem das Aves em Theropoda - Apresentação Interativa

## 📝 Descrição
Apresentação web interativa baseada em Reveal.js explorando a origem evolutiva das aves modernas a partir de dinossauros Theropoda. O projeto inclui scripts Python sofisticados para extração, processamento e organização de imagens científicas de PDFs de pesquisa.

## 🎯 Objetivo
Demonstrar a integração de educação científica com desenvolvimento web moderno, criando uma experiência interativa que explora modificações do plano corpóreo e metabolismo na evolução das aves.

## 💻 Tecnologias Utilizadas
- **Frontend**: HTML5, Reveal.js, CSS3
- **Backend/Automação**: Python
- **Processamento de Imagens**: PIL, PyPDF2
- **Ferramentas**: Jupyter Notebooks, Git
- **Deploy**: GitHub Pages

## 🎨 Features Principais
- ✅ Apresentação interativa com Reveal.js
- ✅ Automação de extração de imagens de PDFs científicos
- ✅ Scripts Python para processamento em lote
- ✅ Launcher automático para Windows
- ✅ Workflow master para execução coordenada
- ✅ Referências científicas integradas

## 📚 Base Científica
Utiliza 5 PDFs científicos principais:
1. Uno & Hirasawa (2023) - Origin of the propatagium
2. Macaulay et al. (2023) - Body shape and mass distribution
3. Nebreda et al. (2021) - Dinosaur-bird macroevolution
4. Foth & Rauhut (2017) - Re-evaluation Archaeopteryx
5. Agnolín & Novas (2013) - Avian Ancestors

## 📊 Resultados & Aprendizados
- Automação inteligente de tarefas repetitivas com Python
- Integração de dados científicos complexos em apresentações web
- Experiência com processamento de PDFs e imagens
- Aplicação prática em educação científica
- Criação de pipelines de automação robustos
