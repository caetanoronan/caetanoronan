# 🚁 Geomarketing Drones Agrícolas - Santa Catarina

## 📝 Descrição
Análise completa do potencial de mercado para operações de aluguel e venda de drones agrícolas em Santa Catarina. Utiliza dados oficiais do IBGE (PAM 2024) para criar mapas interativos que identificam as melhores oportunidades geográficas para negócios com drones agrícolas.

## 🎯 Objetivo
Identificar municípios com maior potencial para operações de drones agrícolas através de análise geoespacial, combinando dados de área agrícola, cultura predominante e concentração de propriedades. Oferecer inteligência de mercado para tomada de decisão estratégica.

## 💻 Tecnologias Utilizadas
- **Frontend**: Folium, Leaflet.js, HTML5, CSS3
- **Análise de Dados**: Python (Pandas, GeoPandas)
- **Visualização**: Matplotlib, Folium
- **Dados**: IBGE PAM 2024, SIDRA
- **Geoespacial**: Shapefiles, GeoJSON
- **Deploy**: GitHub Pages, Render

## 🎨 Features Principais
- ✅ 2 versões de mapas: Web otimizado (1.6 MB) e HD completo (222.7 MB)
- ✅ Score composto de potencial de mercado
- ✅ Análise de 295 municípios de Santa Catarina
- ✅ Mapa de áreas agrícolas (1,68 milhões de hectares)
- ✅ Dashboard interativo com 7 abas
- ✅ Ranking municipal com métricas detalhadas
- ✅ Clustering inteligente de dados
- ✅ Otimização para web e offline
