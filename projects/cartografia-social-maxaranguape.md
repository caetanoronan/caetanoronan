# 📋 Cartografia Social Participativa - Maxaranguape

## 📝 Descrição
Projeto de cartografia social participativa desenvolvido para a comunidade de Maxaranguape, Rio Grande do Norte. Combina pesquisa acadêmica com mobilização comunitária, criando documentos estruturados e apresentações para comunicação de resultados.

## 🎯 Objetivo
Facilitar a participação comunitária no mapeamento de recursos, problemas e potenciais de desenvolvimento local através de cartografia participativa, gerando documentação acadêmica e visual para apresentação.

## 💻 Tecnologias Utilizadas
- **Documentação**: Markdown
- **Ferramentas de Apresentação**: HTML, CSS, JavaScript
- **Análise**: Análise participativa, mapeamento comunitário
- **Gestão**: Git, GitHub
- **Visualização**: Diagramas e mapas temáticos

## 🎨 Features Principais
- ✅ 5 documentos estruturados para exercício acadêmico
- ✅ Resumo completo com formato acadêmico
- ✅ Apresentação estruturada em 8 slides
- ✅ Roteiro de apresentação oral cronometrado (5 min)
- ✅ Guia prático de uso dos arquivos
- ✅ Índice geral organizado

## 📊 Componentes do Projeto

1. **RESUMO_Cartografia_Maxaranguape.md** - Documento principal
2. **APRESENTACAO_Slides_Maxaranguape.md** - Conteúdo dos slides
3. **ROTEIRO_Apresentacao_5min.md** - Guia de apresentação oral
4. **GUIA_DE_USO.md** - Manual de instruções
5. **README.md** - Índice e orientações

## 📊 Resultados & Aprendizados
- Experiência em pesquisa participativa e cartografia social
- Desenvolvimento de documentação acadêmica estruturada
- Criação de materiais para comunicação visual
- Integração de pesquisa com mobilização comunitária
- Capacidade de estruturar projetos complexos com múltiplas documentações
